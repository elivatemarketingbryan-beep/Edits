# The library

Everything the studio can put in an edit, in one place. Generated by `node studio/library.mjs`; don't edit by hand.
`node studio/edit.mjs plan <job>` searches this for you from the transcript. Watch the graphics: `assets/boards/index.html`.

| Kind | Count | Use it by |
|---|---|---|
| Your approved graphics | 37 | copy into the job, change the words and times |
| Story scenes | 2 | a new scene per story with `assets/boards/story/kit.js` |
| Boards (premium look) | 74 | `studio/board-fit.py` |
| Ready-made effects | 15 | `node studio/anim.mjs new <name>` |
| Video FX (9:16) | 17 | skill `fx-<name>` |
| Named sounds | 103 | a cue in `sfx.json` |
