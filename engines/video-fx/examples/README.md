# Examples

One preview per effect (720×1280), the exact config that made it, and a poster frame. `Showreel.mp4` plays all 17 under a live effect list, in the same format as the reel this pack recreates.

Re-create any of them on your own footage: open the `.json`, change the words to match what you say, and ask Claude to "render the <effect> effect on <my video> from <start> to <end> with this config".
