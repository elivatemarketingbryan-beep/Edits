# AI Employee Lab (mode A, 30 s)

The reference piece. Concept: the flask brews an AI employee. Drop → flood → pen draws the flask → ingredient tiles
(Context, Skills, Tools, Memory) dive in → "No code. just Chemistry." → BREWING build with rays and marquees → the employee
pops out and lands → "Hire your first AI employee." → clones into a 64-person team → zooms back to the logo, the employee
drops home, wordmark + LAB pill + tagline, a hop and a bubble.

`logo_traced.svg` is a hand-cleaned vector of `logo_original.png` (the original has soft glows that do not trace well);
`logo/` was made with `logo.py logo_traced.svg logo --raster logo_original.png`. Render: `make.py story.json -o lab.mp4`.
