# drafts/

Text pieces written by `repurposing` and `platform-formats`, one folder per week:
`drafts/YYYY-MM-DD/<platform>-<slug>.md`, plus `00-mined.md` (the ideas mined from the source, with
timestamps). One piece per file so each can be approved on its own. Every file ends with a
`Source:` line. Nothing here is posted until Bryan says so.

Revising a draft keeps the old text under `## Previous version — <date>` at the bottom; nothing is
deleted.
