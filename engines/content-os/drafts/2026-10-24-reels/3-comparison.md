# Comparison reels (10)

Shape: Comparison. Hook names the two sides → alternate lines, every line tagged A or B, sides balanced → verdict → CTA.
Target 1:30-2:00. Clone versus and Dual-role dialogue need two takes filmed (one per side, same framing).

## C01 · A template website vs a website built to book

**Hook:** "Two websites can look almost the same. Only one of them books estimates."
**Beats**
1. Alternate the template site (A) and the site built to book (B) on what each one is designed to do.
2. Keep both sides to the same number of lines.
3. Verdict: a website is judged by what it makes, not how it looks. Follow CTA.
**Delivery:** Point left for A, right for B; the columns fill in.
**Script**
```text
Two websites can look almost the same. Only one of them books estimates. [HOOK]
Same colors, same logo, same nice photo at the top.
But one was built to look good, and one was built to get you on the phone.
The template site has a big photo, a menu and a "contact us" page three clicks deep. [SIDE: A]
The site built to book has a call button that follows you all the way down the page. [SIDE: B]
The template site says "quality you can trust," like every other contractor in town. [SIDE: A]
The site built to book shows forty real jobs and the reviews that came with them. [SIDE: B]
The template site has one page that tries to talk about every service you offer. [SIDE: A]
The site built to book has a page for every service, so the homeowner lands right where they need to be. [SIDE: B]
The template site loads slow on a phone, because nobody tested it on one. [SIDE: A]
The site built to book loads fast on a phone, because that's where homeowners are. [SIDE: B]
The template site sends the form to an inbox you check on Sunday. [SIDE: A]
The site built to book texts the homeowner back before they close the tab. [SIDE: B]
Here's the difference. [EMPHASIS: books]
One website looks good. The other one books jobs.
And when you're paying for ads to send people there, that difference is everything.
```
