# MiroFish scene assets

These files support the MiroFish compositions in `src/custom/mirofish/`, including the full-canvas product display, input collage, and typographic invitation. Retrieved from official sources on 2026-10-07; used locally at render time. Their colors and contents are unchanged.

- `github-invertocat-black.svg`: official GitHub mark from [GitHub's logo archive](https://brand.github.com/GitHub_Logos.zip), linked from its [brand toolkit](https://brand.github.com/foundations/logo). It identifies GitHub as the repository host. GitHub retains its trademark/copyright rights; the mark does not imply endorsement of this editor.
- `mirofish-screenshot-2.png`: actual MiroFish interface screenshot linked from the [official repository README](https://github.com/666ghj/MiroFish/blob/main/README.md). [Original PNG](https://raw.githubusercontent.com/666ghj/MiroFish/main/static/image/Screenshot/%E8%BF%90%E8%A1%8C%E6%88%AA%E5%9B%BE2.png). The composition crops the image and animates its frame; it does not alter the interface or its content.
- `mirofish-screenshot-1.png`: actual product home/upload screen from the same README. [Original PNG](https://raw.githubusercontent.com/666ghj/MiroFish/main/static/image/Screenshot/%E8%BF%90%E8%A1%8C%E6%88%AA%E5%9B%BE1.png). The input-collage scene focuses on its upload area.
- `mirofish-logo.jpeg`: actual fish/mirror logo and wordmark from the [official README image](https://raw.githubusercontent.com/666ghj/MiroFish/main/static/image/MiroFish_logo_compressed.jpeg). The CTA displays the fish portion as an image crop.
- `LICENSE-MiroFish.txt`: upstream [AGPL-3.0 license](https://github.com/666ghj/MiroFish/blob/main/LICENSE) retained alongside the repository screenshot. No separate image-specific license was stated in the README. The project's original-code license does not replace upstream terms.

The community package includes these four visual assets, this record, and the upstream license. Private footage and working job files are excluded. Use fresh assets matching the subject for other videos; these images are not a universal scene template.

Asset sources and usage records stay in project files and are not rendered as video subtitles or footers.
