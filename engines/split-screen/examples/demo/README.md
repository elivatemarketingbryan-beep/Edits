# Original rendering demo

`plan.json` demonstrates a source/graphics split, a full-frame custom animation, and four distinct visual treatments: warm paper and a blue magnifier, a dark luminous signal diagram, a restrained white editorial procedure, and a green-and-cream botanical cutaway. Color and material follow each concept. The neutral black-and-white source fixture gives those scenes room to change character.

`public/demo/source.mp4` is original procedural media generated from `src/SourceFixture.tsx` with a quiet test tone. There is no presenter, spoken transcript, third-party footage, or AI-generated video in this fixture. Its source notes belong here and in the plan; the rendered scenes contain no provenance overlays.

`preview.mp4` is the included 14-second, 540 × 960 preview. `contact-sheet.jpg` samples all four beats. The editable composition renders at 1080 × 1920 when exported without `--draft`.

Run `npm run demo` to regenerate the source and plan, then `npm run demo:render`. The included preview is a demonstration of rendering and composition, not proof of autonomous editing quality on arbitrary footage. Use the full agent workflow for real edits.
